# 🔥 **Fire Detection System using Arduino**  

This project is a **Fire Detection System** built using an **Arduino Uno**, an **MQ-2 smoke sensor**, an **LED**, and a **buzzer**. It detects smoke levels and provides **visual and audible alerts**, making it useful for **fire safety and early warning applications**.  

---

## 🛠️ **Components Used**  
- 🔹 **Arduino Uno** – Processes sensor data and controls outputs.  
- 🔹 **MQ-2 Smoke Sensor** – Detects smoke and gas levels.  
- 🔹 **LED** – Provides a visual alert when smoke is detected.  
- 🔹 **Buzzer** – Emits a sound alert for fire warnings.  

---

## ⚙️ **How It Works**  
1️⃣ The **MQ-2 smoke sensor** continuously monitors air quality.  
2️⃣ If **smoke concentration exceeds a set threshold**, the **Arduino activates the LED and buzzer**.  
3️⃣ The system **automatically resets** once the smoke level returns to normal.  

---

## 📝 **Features**  
✅ **Detects smoke and gas leaks** using an MQ-2 sensor  
✅ **Turns ON an LED** for a visual warning  
✅ **Activates a buzzer** for an audible alarm  
✅ **Adjustable sensitivity** based on smoke levels  
✅ **Automatically resets** when air quality improves  

---

## 🌍 **Applications**  
🔹 **Fire Alarm System** – Provides early warning for fire hazards.  
🔹 **Gas Leak Detection** – Detects harmful gases in homes and industries.  
🔹 **Smart Home Safety** – Can be integrated into home automation systems.  
🔹 **Industrial Safety** – Monitors smoke levels in factories and warehouses.  
🔹 **Kitchen Safety** – Alerts users of excess smoke while cooking.  
🔹 **Remote Fire Monitoring** – Can send alerts to IoT-based platforms.
